SAVE YOUR WORK TO GITHUB (use any time)
1. Copy these 3 files into your project folder (C:\Users\itsme\Documents\chennaideals.in-git), replacing the old ones.
2. Double-click Sync-To-GitHub.bat (or run it from the project folder).
3. Type a short description and press Enter.
It commits everything, then uploads to the branch you are on. It never uses force, skips passwords/.env/uploads/backups, and stops without touching GitHub if GitHub has newer changes.
